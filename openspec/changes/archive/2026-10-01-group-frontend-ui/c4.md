# Diagramas C4

O recorte só agrupa a interface Vue. Contexto, pack `auctions`, banco, event store e canal permanecem.

## Contexto

```mermaid
C4Context
title Contexto inalterado

Person(seller, "Vendedor")
Person(bidder, "Licitante")
System(house, "Casa de Leilões", "Publica leilões e confirma um lance por vez")

Rel(seller, house, "Publica")
Rel(bidder, house, "Dá lance e observa")
```

## Componentes

```mermaid
C4Component
title Pasta ui neste change

Container_Boundary(front, "Frontend Vue") {
  Component(pages, "ui/pages", "Vue", "Início, publicar e sala")
  Component(widgets, "ui/components", "Vue", "Barra de participante")
  Component(root, "Composition root", "TypeScript", "Liga data a infra")
  Component(data, "data", "TypeScript", "Publicar, dar lance, aplicar preço")
  Component(domain, "domain", "TypeScript", "Dinheiro e sala")
  Component(infra, "infra", "TypeScript", "Inertia e Action Cable")
}

Rel(pages, widgets, "Renderiza")
Rel(pages, root, "Usa")
Rel(widgets, root, "Usa")
Rel(root, data, "Chama")
Rel(root, infra, "Injeta")
Rel(pages, domain, "Formata preço")
```

## Fronteiras entre packs

- O pack `auctions` continua o único bounded context. A web chama a API pública e não importa `data` nem `infra` do pack.
- `ui` não importa o cliente do Action Cable nem o adapter HTTP.
- `domain` do frontend não importa Vue, Inertia nem Action Cable.
- `data` depende de domínio e de portas. `infra` implementa as portas.
- O composition root fica fora de `ui` e é o único lugar que liga `data` a `infra`.
