# Diagramas C4

O recorte troca o nome de duas pastas no navegador e no pack `auctions`. Contexto, banco, event store e canal permanecem.

## Contexto

```mermaid
C4Context
title Contexto inalterado

Person(seller, "Vendedor")
Person(bidder, "Licitante")
System(house, "Casa de Leilões", "Publica leilões e confirma um lance por vez")

Rel(seller, house, "Publica")
Rel(bidder, house, "Dá lance e observa")
```

## Componentes

```mermaid
C4Component
title Pastas renomeadas neste change

Container_Boundary(ui, "Interface Vue") {
  Component(pages, "Páginas", "Vue", "Publicar, sala e participante")
  Component(root, "Composition root", "TypeScript", "Liga data a infra")
  Component(data_ui, "data", "TypeScript", "Publicar, dar lance, aplicar preço")
  Component(domain_ui, "domain", "TypeScript", "Dinheiro e sala")
  Component(infra_ui, "infra", "TypeScript", "Inertia e Action Cable")
}

Container_Boundary(pack, "Pack auctions") {
  Component(public_api, "public", "Ruby", "API Auctions")
  Component(data_rb, "data", "Ruby", "Casos de uso")
  Component(domain_rb, "domain", "Ruby", "Agregado e eventos")
  Component(infra_rb, "infra", "Ruby", "Event store, projeção e relógio")
}

Rel(pages, root, "Usa")
Rel(root, data_ui, "Chama")
Rel(root, infra_ui, "Injeta")
Rel(data_ui, domain_ui, "Usa")
Rel(public_api, data_rb, "Chama")
Rel(data_rb, domain_rb, "Usa")
Rel(data_rb, infra_rb, "Usa")
```

## Fronteiras entre packs

- O pack `auctions` continua o único bounded context. A web chama a API pública e não importa `data` nem `infra` do pack.
- `domain` do pack não referencia Rails, Inertia nem Action Cable.
- `domain` do frontend não importa Vue, Inertia nem Action Cable.
- `data` depende de domínio e de portas. `infra` implementa as portas e fala com event store, projeção ou canal.
- `pages` não importa o cliente do canal.
