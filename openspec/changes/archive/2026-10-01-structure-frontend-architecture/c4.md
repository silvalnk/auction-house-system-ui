# Diagramas C4

O navegador continua sendo um contêiner. Este change só separa os componentes dentro dele. O pack `auctions` e o Action Cable permanecem como no RFC arquivado.

## Contexto

```mermaid
C4Context
title Contexto inalterado

Person(seller, "Vendedor")

Rel(bidder, house, "Dá lance e observa")
```

## Componentes

```mermaid
C4Component
title Componentes do frontend neste change

Container_Boundary(ui, "Interface Vue") {
  Component(pages, "Páginas", "Vue", "Publicar, sala e participante")
  Component(root, "Composition root", "TypeScript", "Liga portas aos adapters")
  Component(usecases, "Casos de uso", "TypeScript", "Publicar, dar lance, aplicar preço")
  Component(domain, "Domínio de leitura", "TypeScript", "Dinheiro e sala")
  Component(inertia, "Adapter Inertia", "HTTP", "POST de publicação, lance e sessão")
  Component(cable, "Adapter Action Cable", "WebSocket", "Entrega preço confirmado")
}

Rel(pages, usecases, "Chama")
Rel(root, usecases, "Injeta")
Rel(root, inertia, "Implementa comando")
Rel(root, cable, "Implementa sala")
Rel(usecases, domain, "Usa")
```

## Fronteiras entre packs

- `domain` não importa `vue`, `@inertiajs/vue3` nem `@rails/actioncable`.
- `application` importa domínio e interfaces de porta, não os adapters.
- `infrastructure` importa as bibliotecas externas e implementa as portas.
- `pages` importa casos de uso ou funções já compostas, não o cliente do canal.
- Nenhuma dessas pastas importa classe do pack Rails `auctions`.
